# 引き継ぎ指示書（2026-11-14）

別エージェントがこの文書だけで作業を再開できるようにまとめたもの。
まず `AGENTS.md` を読み、その規則（ローカル Quartus フルビルド禁止、np21w 基準、
lint/firmware/CI/JTAG 手順）に従うこと。

## 共通ルール

- 返答は日本語・簡潔。
- push: `git -c credential.helper= -c credential.helper='!gh auth git-credential' push origin <branch>`
- CI: `gh workflow run build.yml -R MusiQ-DA/pc98-pocket --ref <branch>`（ポーリングは 3 分以上空ける）
- Quartus ログ: `gh api --allow-escape-sequences repos/MusiQ-DA/pc98-pocket/actions/jobs/<job id>/logs`
  → `Logic utilization` / `requires N LABs` / 全ての `Worst case slack` を確認。
  **fit かつ setup/hold 違反ゼロ**が合格条件。違反時は SEED 28〜31 を一時ブランチで振る
  （`fpga/ap_core.qsf` の `set_global_assignment -name SEED`）。
- firmware: `cd firmware && PATH="/opt/homebrew/opt/llvm/bin:$PATH" make`、
  `firmware.vh`/`firmware.bin` を必ずコミット。cherry-pick で firmware.vh/.bin は
  必ず衝突する → そのブランチのプロファイルで再ビルドしてコミット。
- `--timing` sim は pc98-sim docker（Verilator 5.020）で。
- 実機: `scripts/jtag_flash.sh <sof>`（デバッグ版のみ JTAG 可）、SD は
  `bash scripts/deploy.sh --run <run番号>`（バックグラウンド、カード待ち 90 分で打ち切り）。
  deploy は実行したワークツリーの `firmware.bin` を使うので、対象ブランチのワークツリーで実行。
- コミット末尾:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01H6QCgDqMQjbvbUQVhDQcEP
  ```
- マージはユーザーの実機確認後のみ。サブエージェントは flash/SD/merge しない。
