## 残る問題 (1つに絞られた)

**パス2でも POP SS (F000:7D80) が 0xF202 をロードする。** このルーチンは
`pop ss; inc bx; ... and di,0xE000; shr di,13` — 共有エピローグの一種で、
本来は呼び出し側のプロローグ (`push ss`) と対になる。我々のマシンは
エントリスタブ (E800:0A07→F7EF3-F7F16) の **[0x1862]/[0x1866]/[0x186C]/
[0x1860] 分岐**で間違ったパスに入り、プロローグを飛ばしてF7D80に達する。

**実測スタック (両パス共通):**
```
[F8]=0x0A07 [FA]=0xFD80 [FC]=0xF202 [FE]=0x0000
```
0xF202 は 8086 フラグの定番値 (bit12-15=1, IF=1, bit1=1) = int 1E の
プッシュしたフラグ。0x0A07 は `push es` の値 (ES=0x0A07 — これも異常値)。
